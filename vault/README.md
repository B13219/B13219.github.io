# Vault website

Static GitHub Pages build for the Vault photography and film studio website.

## Structure

```text
vault/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── brand/
    └── work/
        └── exim-bank/
```

- `assets/brand/` contains Vault logos, the favicon, and social preview artwork.
- `assets/work/<project>/` contains each commissioned project's photographs and films.
- New client projects should receive their own folder under `assets/work/`.

The live site is available at <https://b13219.github.io/vault/>.
